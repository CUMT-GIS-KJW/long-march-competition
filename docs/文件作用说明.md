# 文件作用说明

本文说明当前项目中每个文件的作用。`.git/` 属于 Git 内部目录，不列入项目文件说明。

## 根目录

| 文件 | 作用 |
| --- | --- |
| `.env` | 本地环境变量文件，保存真实密钥或端口配置，不上传 GitHub。 |
| `.env.example` | 环境变量示例文件，可上传 GitHub，说明需要配置 `DEEPSEEK_API_KEY` 和模型名。 |
| `.gitattributes` | Git 文本处理配置，用于统一仓库中文件属性。 |
| `.gitignore` | Git 忽略规则，当前忽略 `.env`、`node_modules/` 和 npm 调试日志。 |
| `package.json` | 项目脚本和 Node 运行配置，`npm.cmd start` 会启动 `server/app.js`。 |
| `package-lock.json` | npm 锁定文件，记录依赖解析结果，保证不同机器安装结果一致。 |
| `README.md` | 项目总说明，包含模块结构和运行方式。 |
| `启动项目.cmd` | Windows 一键启动脚本，启动服务并打开浏览器。 |

## 服务入口

| 文件 | 作用 |
| --- | --- |
| `server/app.js` | Node HTTP 服务入口，负责加载环境变量、分发 API、提供静态页面和资源。 |

## 共享模块

| 文件 | 作用 |
| --- | --- |
| `features/shared/backend/data-store.js` | 后端数据读取工具，集中读取 `data` 中的 JSON 和路线图层数据。 |
| `features/shared/backend/env.js` | 后端 `.env` 文件加载工具。 |
| `features/shared/backend/http.js` | 后端 HTTP 响应工具，统一返回成功、错误和静态内容。 |
| `features/shared/backend/static-files.js` | 后端静态文件服务，映射 `/index.html`、`/analysis.html`、`/scene3d.html` 到功能目录页面。 |
| `features/shared/frontend/app.css` | 共享基础视觉样式和旧版通用布局样式。 |
| `features/shared/frontend/base.css` | 前端基础主题样式，导入 `app.css` 并设置 Leaflet、色彩和地图基础风格。 |
| `features/shared/frontend/config.js` | 前端全局配置，定义 API 路径、静态数据路径、地图中心和三维地形配置。 |
| `features/shared/frontend/data-service.js` | 前端数据服务，封装路线、事件、资源、分析数据和三维焦点数据的读取。 |
| `features/shared/frontend/map-utils.js` | 前端地图工具，提供事件图标、弹窗、类型名称和数字格式化等通用方法。 |

## 主地图功能 home

| 文件 | 作用 |
| --- | --- |
| `features/home/backend/index.js` | 主地图相关后端 API，提供路线图层、事件时间线、路线数据和红色资源接口。 |
| `features/home/frontend/index.html` | 主地图页面入口，展示二维地图、路线图层、事件过滤、播放控制和 AI 面板。 |
| `features/home/frontend/home.css` | 主地图核心样式，定义页面布局、侧栏、地图标题、图例、播放栏和响应式规则。 |
| `features/home/frontend/home-enhancements.css` | 主地图增强样式，定义时间轴、路线图层卡片、节点动画和部分交互视觉。 |
| `features/home/frontend/home-map.js` | 主地图业务脚本，初始化 Leaflet 地图、加载路线/事件/资源、播放事件和路线动画。 |
| `features/home/frontend/home-ui.js` | 主地图交互脚本，绑定按钮、折叠面板、事件过滤、图例开关和播放控制。 |

## 综合分析功能 analysis

| 文件 | 作用 |
| --- | --- |
| `features/analysis/backend/index.js` | 综合分析后端 API，提供统计摘要、省域、地形、缓冲区和阶段分析数据。 |
| `features/analysis/frontend/index.html` | 综合分析页面入口，展示分析工具箱、专题地图、指标面板、图表和结论区。 |
| `features/analysis/frontend/analysis.css` | 综合分析核心样式，定义三栏布局、工具按钮、专题地图、图例、指标和底部结论。 |
| `features/analysis/frontend/warm-theme.css` | 综合分析暖色主题增强样式，统一比赛展示风格和部分地图标记效果。 |
| `features/analysis/frontend/analysis-map.js` | 综合分析地图脚本，初始化 Leaflet 分析地图，绘制路线、事件、资源和分析结果图层。 |
| `features/analysis/frontend/analysis-ui.js` | 综合分析交互脚本，绑定工具切换、模型执行、ECharts 图表、结论文本和提示消息。 |

## 三维场景功能 scene3d

| 文件 | 作用 |
| --- | --- |
| `features/scene3d/backend/index.js` | 三维场景后端 API，提供遵义会议核心点位和三维场景焦点数据。 |
| `features/scene3d/frontend/index.html` | 三维场景页面入口，展示 Cesium 场景、空间档案、图例和控制按钮。 |
| `features/scene3d/frontend/scene3d.css` | 三维场景样式，定义侧栏档案、Cesium 容器、图例、操作提示和底部控制栏。 |
| `features/scene3d/frontend/scene3d.js` | 三维场景脚本，初始化 Cesium、加载 DEM 地形、绘制路线、核心点、辅助节点和镜头控制。 |
