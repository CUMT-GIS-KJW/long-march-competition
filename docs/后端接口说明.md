# 后端接口说明

所有成功响应统一为 `{ "code": 200, "message": "success", "data": ... }`。

- `GET /api/events`：历史节点
- `GET /api/routes`：三军路线
- `GET /api/resources`：红色资源
- `GET /api/analysis/summary`：指标概览
- `GET /api/analysis/province`：省域统计
- `GET /api/analysis/elevation`：海拔剖面
- `GET /api/analysis/buffer`：缓冲统计
- `GET /api/analysis/stage`：阶段统计
- `GET /api/scene3d/focus`：遵义会议三维核心点配置
