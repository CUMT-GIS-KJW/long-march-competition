# 页面交互逻辑说明

## 主界面

1. `DataService` 读取事件、三军路线和红色资源 JSON。
2. `IndexMap` 用 Leaflet 创建底图、路线、节点、图像注记和图层开关。
3. 左侧时间线按 `stage`、`type` 筛选；节点按照 `importance` 随缩放等级显示。
4. 点击时间线、地图节点或地图照片，统一触发 `eventselect`，右侧立即更新历史叙事、图像、关键指标和坐标。
5. `RouteAnimator` 每约 4.8 秒推进一个路线折点；进度同时驱动当前节点和右侧叙事。
6. 地图影像使用水滴形空间注记，点击展开、6 秒后收起；当前播放节点使用双层扩散与浮动动画。
7. 主地图保持 Leaflet 二维表达，播放器使用单一 `requestAnimationFrame` 时钟，同步更新路线进度、行军标记、底部进度条和左侧时间轴，避免路线头滞后。
8. 左侧时间轴按照“已完成、当前、未到达”三种状态动态变化，并自动滚动到当前节点。
9. 点击遵义会议节点后，右侧出现“进入遵义会议三维场景”入口；三维能力独立位于 `features/scene3d/frontend/index.html`，并通过 `/scene3d.html` 兼容访问。

## 三维核心点页面

1. CesiumJS 负责三维地球、长征路线、核心光柱、辅助节点和镜头控制。
2. 遵义会议是唯一核心重建点，其他重要节点只使用小光柱和标签。
3. 当前使用纪念标志几何占位，后续可通过 `scene3d-focus.json` 中的模型路径替换为 3DGS 模型。

## GIS 分析界面

1. 输入数据：长征路线、历史节点、红色资源点、DEM/海拔数据。
2. 空间处理：路线统计、地形剖面、Turf 多尺度缓冲、类型统计、资源关联。
3. 成果表达：Leaflet 专题图层、核心指标、ECharts 图表和底部分析结论。
4. 当前使用 JSON 演示数据；切换 `features/shared/frontend/config.js` 的 `dataMode` 后可读取后端 API。
